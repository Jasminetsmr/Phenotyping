# Phenotyping of Chili Seedlings 🌱🌶️

This project focuses on the phenotyping of chili seedlings (Capsicum annuum L.) using image-based data and deep learning techniques (YOLOv5). The goal is to detect the viability and health condition of seedlings.

> ✅ **The web-based application is currently in progress** for real-time phenotyping and monitoring of seedling health.
